# AgroChain Gold: IoT-Blockchain Food Traceability System

## 📌 Project Overview
[cite_start]A decentralized framework for precision agriculture using **Ethereum smart contracts** and **IoT technology**[cite: 28, 29].

## 🚀 Key Features
* [cite_start]**Immutable Data**: Implemented **Solidity** smart contracts on **Ganache** to record non-manipulable sensor data[cite: 28, 30].
* [cite_start]**Web3 Dashboard**: Built a real-time interface for batch tracking and **AI-driven harvest yield prediction**[cite: 31].
* [cite_start]**Precision Analytics**: Uses **Scikit-Learn** for predictive environmental monitoring.

## 🛠️ Tech Stack
* [cite_start]**Blockchain**: Solidity, Ganache, Web3.js.
* [cite_start]**Machine Learning**: Python, Pandas, Scikit-Learn[cite: 32, 43].
* [cite_start]**Frontend**: HTML5, CSS3, JavaScript[cite: 38, 42].

## ⛓️ Smart Contract Development (Remix IDE)
The core logic is handled by `AgroContract.sol`, developed and tested using the **Remix IDE**.
* [cite_start]**Data Integrity**: Implements state variables to store immutable IoT sensor readings (temperature, humidity, soil moisture)[cite: 29, 30].
* [cite_start]**Batch Tracking**: Uses mappings and structs to track produce batches from harvest to distribution[cite: 31].
* **Access Control**: Includes owner-only functions to ensure only authorized IoT gateways can update data.

## 🖥️ Web3 Dashboard Details
The frontend provides a real-time interface for stakeholders to interact with the blockchain.
* [cite_start]**Real-time Integration**: Uses **Web3.js** to fetch and display live data directly from the Ganache local blockchain[cite: 28, 31].
* [cite_start]**AI Yield Prediction**: Features a dashboard component that runs **Scikit-Learn** models to predict future harvest yields based on historical IoT data[cite: 31, 33].
* [cite_start]**User Interface**: Built with **HTML5, CSS3, and JavaScript** for a responsive, mobile-friendly experience[cite: 38, 42].
